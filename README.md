# MicroBi
Um SaaS focado em quem acha o Power BI ou Looker Studio complexo demais. O usuário faz upload de planilhas de vendas/financeiro e a plataforma gera automaticamente um dashboard limpo, interativo e pronto com os principais KPIs (CAC, LTV, Ticket Médio, faturamento mensal), com opção de exportar relatórios executivos em PDF.
